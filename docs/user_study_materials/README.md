# Blinded study materials

These files were built from validation artifacts only. No API call or frozen test-set run is required.

Study status: five participant-provided completed questionnaires were imported on 2026-09-22. Normalized observations, preferences and validation metadata are in `results/real_user_study_*`; the descriptive report is `docs/real_user_evaluation.md`. Archived originals and the facilitator decoding key are retained in the local assessment archive and intentionally excluded from the public repository. These results remain separate from the synthetic evaluator pilot.

- Send each participant only their matching `Pxx_participant_packet.md` file.
- Printable Word versions are available in `output/user_study_questionnaires/AccountLens_Blinded_Questionnaire_P01.docx` through `P05.docx`. Give each participant only the file matching their anonymous code.
- Each Word questionnaire tells the participant exactly what to complete: consent/profile checks, four account reviews, eight briefing response forms, preparation time, six ratings per briefing, and four paired A/B assessments.
- Keep `facilitator_key.md` private until all scoring is complete.
- Enter observed times and ratings in `facilitator_recording_sheet.md`; never fill missing observations with simulated values.
- Do not tell participants which briefing is B0 or M2.
- Record only anonymous participant codes; do not collect employer or customer data.
- These packets use the same headings, account metadata, evidence register, rating scale and limitations for both systems.
- B0 contains deterministic activity/risk logic and rule-based roles; M2 contains the saved evidence-grounded validation briefing plus the same deterministic risk layer.
- Real participant results must be reported separately from the synthetic evaluator pilot.
- The five Word questionnaires were rendered and visually checked page by page; each final file is 21 pages with no blank pages.
